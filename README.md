# Dom Wise — Private Chef

A responsive, buildless website for Dom Wise’s private dining, weekly meal preparation, and family chef / nanny services in the Boston area.

## Run locally

Open `index.html` directly or serve the repository root with any static file server. No build step or package install is required.

## Site notes

- The design is a warm, cookbook-inspired portfolio built around Dom’s name, a custom chef-toque mark, culinary photography, and straightforward service descriptions.
- All 68 culinary images from the supplied Google Drive folder are represented across the featured sections, gallery, and lightbox. The most appetizing, well-composed dishes now lead the homepage and gallery. Featured service images share equal tile dimensions; the portfolio uses a compact masonry layout that preserves each image’s original composition and reveals the archive in small batches.
- Images load from Google-hosted URLs, so the source files need to remain link-accessible.
- Dom’s hero portrait is the temporary image supplied for the draft. Replace the image source in the hero section when a new portrait is ready.
- The longer profile highlights Dom’s adaptability across professional and private kitchens and his current work at Marzae Cellar + Provisions in Boston’s Haymarket area. Confirmed résumé details and specialties can be added when provided.
- The inquiry form is designed but cannot send or store entries until Dom’s booking email or form endpoint is connected. The submit button stays disabled until then.
