# Dom Wise — Private Chef

A responsive, buildless portfolio page for Dom Wise's private chef in the Boston area, meal prep, and family chef / nanny services.

## Run locally

Open `index.html` directly, or serve the repository root with any static file server. No build step or package install is required.

## Site notes

- Portfolio photographs and the two credential scans are loaded from the public Google Drive folder supplied for this project. Keep those files shared publicly for the images to appear.
- `cert1` is displayed as the ServSafe certificate; `cert2` is displayed as the Emergency Care & Safety Institute completion certificate, in a separate credentials section.
- The public background is limited to private chef work and prior kitchen experience at Dragon Pizza in Somerville. Full role dates, culinary specialties, and the preferred booking contact can be added when confirmed.
- The booking panel is intentionally not wired to an unverified email or inquiry service.
