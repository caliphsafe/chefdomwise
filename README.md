# Dom Wise — Private Chef

A responsive, buildless portfolio website for Dom Wise’s private chef, meal preparation, and family chef / nanny services in the Boston area.

## Run locally

Open `index.html` directly, or serve the repository root with any static file server. No build step or package install is required.

## Site notes

- The kitchen archive displays all 68 culinary image files currently in the supplied Google Drive folder. The images load from Google’s shared image URLs, so the source files need to remain link-accessible.
- The portrait in the hero is a temporary image supplied for the draft and can be replaced by updating the `img` source in the hero section.
- `cert1` is presented as Dom Wise’s ServSafe certificate. `cert2` is presented as an Emergency Care & Safety Institute certificate of completion. Both appear in the credentials section, separate from the food gallery.
- The profile notes Dom’s current work at Marzae Cellar + Provisions in Boston’s Haymarket area. The full culinary résumé and specialties can be added when provided.
- The booking section is ready for Dom’s preferred email, phone, or inquiry link, which has not yet been confirmed.
